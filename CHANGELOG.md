# Changelog

## 0.3.1

- Added green names for PvP-flagged players, independent of health bar class colors.
- Restore normal name colors when flags change or plates are reused.
- Simplified documentation and standardized internal naming.

## 0.3.0

- Added `/fplates` and `/foreverplates` commands.
- Added compact and classic oval nameplate styles.
- Added optional player class colors.
- Added centered numerical health and right-aligned percentages.
- Improved name and health text readability with built-in Forever fonts.
